# Code of Conduct

We verwachten respectvolle communicatie en samenwerking.
- Geen beledigingen of intimidatie
- Constructieve feedback
- Geef context en reproduceerbare stappen bij bugs

Overtredingen kunnen leiden tot moderatie of ban in het project.
