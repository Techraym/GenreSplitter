# Support

## Bugs
Maak een GitHub issue aan met:
- stappen om te reproduceren
- relevante logregels (zonder tokens)
- versie + OS

## Feature requests
Leg uit:
- welk probleem je oplost
- waarom dit past binnen “closed genres / deterministic output”

## v2.10.8 – UI & Documentation Update
**Release date:** 27-December-2025

- Dropdowns now show a clear ▼ arrow indicator

- Improved contrast, focus and hover states
